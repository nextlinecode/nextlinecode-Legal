# Nextlinecode Legal

Public legal documents for Nextlinecode apps. MatchPop documents are generated from the private MatchPop application's legal text and published as static HTML.


## Weekline

Static privacy policies and terms: [language index](https://nextlinecode.github.io/nextlinecode-Legal/Weekline/).

Locales: `ko`, `en`, `es`, `ja`, `zh-Hans`, `zh-Hant`. Each has `Weekline/<locale>/privacy.html` and `terms.html`.

Edit `Weekline/content.json`, then run `python3 Weekline/generate.py`. No build dependencies or client-side scripts. Preserve generated HTML in Git for GitHub Pages.

Operator/contact: nextlinecode / nextlinecode@gmail.com. Effective date: 2026-10-16. Analytics retention was not confirmed by the operator; policies describe the configured property rules rather than assuming a fixed period. Recheck against actual Firebase settings and app data practices when changing the service.
